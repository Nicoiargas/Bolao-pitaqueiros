## 🚀 COMO COMEÇAR

### Em 3 Passos Rápidos:

```bash
# 1. Clonar/Copiar arquivos
mkdir palpiteiros-hexa && cd palpiteiros-hexa
# (Copiar todos os arquivos aqui)

# 2. Instalar dependências
npm install

# 3. Rodar localmente
npm run dev
# Acesse: http://localhost:5173
```

### Para Deploy em Produção:

```bash
# Build
npm run build

# Deploy (grátis no Firebase)
firebase deploy
# Seu app estará em: https://palpiteiros-hexa.web.app
```

## 🎮 SISTEMA DE PONTUAÇÃO

| Fase | Acertou Resultado | Cravou Placar |
|------|-------------------|---------------|
| Grupos | 1 ponto | 3 pontos |
| Pré-Oitavas | 1,5 ponto | 4,5 pontos |
| Oitavas | 3 pontos | 9 pontos |
| Quartas | 6 pontos | 18 pontos |
| Semis | 12 pontos | 36 pontos |
| Final | 24 pontos | 72 pontos |

**Exemplo:**
- Placar real: Brasil 2 x 1 Argentina (Oitavas)
- Você chutou: 2 x 1 → **9 pontos!** 🎯
- Outro chutou: 1 x 0 → **3 pontos**
- Outro errou tudo → **0 pontos**
